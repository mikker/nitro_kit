# Nitro Kit 2.0 component contracts

This is the shipped public catalog for `2.0.0.pre.1`. It describes current Ruby construction, rendered roots, closed vocabularies, and compound cardinalities. Candidate abstractions and the historical delivery plan are not public API.

## Shared component boundary

Every visual component accepts:

```ruby
html: {}, aria: {}, data: {}, desperately_need_a_class: nil
```

Many components also expose `id:` or other common native semantics directly. Less common native attributes belong in `html:`. ARIA attributes belong in `aria:` and application data attributes belong in `data:`.

Nitro Kit reserves `data-nk`, `data-slot`, `data-variant`, `data-size`, `data-state`, and `data-nk-escape`. Application `data-controller` and `data-action` values compose additively with Nitro behavior; other owned-data collisions raise. `class` and `style` are rejected, including inside `html:`.

The single styling escape is `desperately_need_a_class:`. It requires a non-blank string and emits both the class and `data-nk-escape="class"`. There is no untyped structural bypass.

`Field` accepts:

```ruby
NitroKit::Field.new(
  form = nil,
  field_name = nil,
  as: :string,
  label: nil,
  description: nil,
  errors: nil,
  options: nil,
  option_tags: nil,
  include_blank: nil,
  prompt: nil,
  id: nil,
  name: nil,
  value: NitroKit::Field::UNSET,
  placeholder: nil,
  disabled: false,
  readonly: false,
  required: false,
  autocomplete: nil,
  checked: nil,
  indeterminate: false,
  multiple: false,
  accept: nil,
  min: nil,
  max: nil,
  step: nil,
  pattern: nil,
  inputmode: nil,
  checked_value: "1",
  unchecked_value: "0",
  include_hidden: true,
  html: {},
  aria: {},
  data: {},
  control_html: {},
  control_aria: {},
  control_data: {},
  desperately_need_a_class: nil
)
```

Field types are `button color date datetime datetime_local email file hidden month number password range search string tel text time url week select textarea checkbox radio radio_button radio_group switch`. `string` becomes a text input; `datetime` and `datetime_local` become `datetime-local`.

## Non-visual Rails integration

`NitroKit::Choice` is a validated value object with `label:`, `value:`, `disabled: false`, and `id: nil`. `Choice.coerce` accepts an existing Choice, a matching Hash, a one-to-four-element array, or a scalar used for both label and value.

`NitroKit::FormBuilder` is selected explicitly through Rails `form_with`. Its Nitro methods are:

- `field`, `fieldset`, and `group`.
- `select`, `radio_button`, `check_box`/`checkbox`, and `hidden_field`.
- `submit` and `button`.
- Rails-shaped color, date, datetime, email, file, month, number, password, phone/telephone, range, search, text, textarea, time, URL, and week field methods.

It has no Nitro root and does not provide `nk_form_with`, `nk_form_for`, or an ERB component bridge. See [Rails and Hotwire integration](rails_integration.md).
